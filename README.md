# Dirty Cafe Sales Analysis
## Objetivo
Explorar y limpiar un dataset de ventas de cafetería para obtener insights básicos sobre productos, ventas y calidad de los datos.

## Dataset
Dataset: *Dirty Cafe Sales*  
Fuente: Kaggle

## Herramientas utilizadas
• Python
• Pandas
• Numpy
• Matplotlib
• Seaborn
• Jupyter Notebook
